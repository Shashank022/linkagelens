# Changelog

## 0.2.0

- Added Maven Guardian lifecycle integration.
- Standardized Maven artifact coordinates on the product namespace `io.linkagelens`.
- Added Maven Central release metadata, sources, Javadocs, GPG signing, and Central Portal publishing support.

## 0.1.0

- Initial LinkageLens CLI.
- JVM class-file constant-pool analysis.
- Recursive nested/fat-JAR scanning.
- LL1001 missing class detection.
- LL1002 missing method detection.
- LL1003 missing field detection.
- LL1004 conflicting duplicate class detection.
- LL1005 Java class-file version mismatch detection.
- Text, JSON, and SARIF output.
- CI severity gating.
